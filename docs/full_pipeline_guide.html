물체별 40개 시연으로 ACT를 학습하고 10,000 step마다 저장한다. 최종 데모는 실제 로봇 비교를 위해 50,000-step checkpoint를 우선 사용한다.

ACT 단독 추론

MODEL_PREFIX=act_v2_full100k \
./src/scripts/imitation_learning/run_act_object.sh syringe \
  --checkpoint 050000 --episodes 1 --episode-time 30 --action-steps 100

ACT에는 현재 validation 기반 자동 best 선정이 없다. last가 최적이라는 보장이 없으므로 실제 로봇 성공률로 checkpoint를 비교한다.

5. Main/Assist Tray 좌표

대각선 트레이를 정확히 표현하기 위해 3~8개 외곽점의 다각형 ROI를 사용한다.

python ./src/scripts/tray/calibrate_tray_rois.py \
  --camera 4 --min-points 3 --max-points 8
  1. 외곽점을 순서대로 선택한다.
  2. 픽셀 좌표를 0~1로 정규화한다.
  3. YOLO bbox 중심점을 구한다.
  4. OpenCV pointPolygonTest로 Main/Assist 내부 여부를 판정한다.
bbox center가 Main polygon 내부   → main
bbox center가 Assist polygon 내부 → assist
둘 다 외부 또는 검출 불안정       → unknown

카메라나 트레이 위치가 변경되면 반드시 다시 보정한다. Main과 Assist 다각형은 겹치면 안 된다.

CLI 전체 실행

PATIENT_NAME="환자A"
DISEASE="감기"

./src/scripts/pipeline/run_cold_scenario.sh "${DISEASE}" \
  --patient "${PATIENT_NAME}" \
  --checkpoint 050000 \
  --action-steps 100 \

UI는 입력을 완료한 뒤에만 모니터로 전환한다. 왼쪽은 의료 장비 확인 화면, 오른쪽은 의료 장비 전달 수행 화면이다.

7. 성공·재시도·중단 조건

시점판정처리
작업 전Main 연속 5프레임ACT 실행 허용
작업 전Assist이미 전달된 것으로 종료
작업 전Unknown로봇 미동작, 종료 코드 3
작업 후Assist 연속 5프레임성공 및 자동 종료
작업 후Main 연속 5프레임초기 자세에서 제한적 재시도
작업 후Unknown낙하·파지 가능성 때문에 재시도 차단

소프트웨어 긴급 정지는 SIGINT로 정상 종료를 요청한다. 물리 비상정지를 대체하지 않는다. 본 시스템은 실제 임상용이 아니라 교육용 팬텀 데모다.
